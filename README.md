## Week 1: Cyber Security Fundamentals & Network Basics

**Objective:** Build a strong foundation in cyber security concepts, networking fundamentals, and how data travels across networks.

| Task | Topic | Marks |
|---|---|---|
| 1 | Introduction to Cyber Security (definition, importance, CIA Triad, applications) | 20 |
| 2 | Types of Cyber Threats (Malware, Virus, Ransomware, Phishing, Spyware, Trojan, DoS) | 15 |
| 3 | Network Basics (LAN/MAN/WAN, IP, MAC, Router, Switch, Modem, DNS) | 20 |
| 4 | Internet Communication Process (client-server, HTTP/HTTPS, DNS lookup, packets) | 15 |
| 5 | Network Security Basics (Firewall, Antivirus, VPN, Encryption, Authentication) | 15 |
| 6 | Practical Activity (Option A: office network diagram) | 15 |
| | **Total** | **100** |

**Key outcomes**
- Explained the CIA Triad and its application to an e-commerce platform.
- Analysed seven common cyber threats with prevention methods.
- Described core networking concepts with diagrams.
- Mapped the full journey of a web request from client to server and back.
- Designed a labelled office network diagram with private IP addressing.
