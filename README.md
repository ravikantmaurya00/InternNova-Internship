## Week 1: Cyber Security Fundamentals & Network Basics

**Objective:** Build a strong foundation in cyber security concepts, networking fundamentals, and how data travels across networks.

| Task | Topic | Marks |
|---|---|---|
| 1 | Introduction to Cyber Security (definition, importance, CIA Triad, applications) | 20 |
| 2 | Types of Cyber Threats (Malware, Virus, Ransomware, Phishing, Spyware, Trojan, DoS) | 15 |
| 3 | Network Basics (LAN/MAN/WAN, IP, MAC, Router, Switch, Modem, DNS) | 20 |
| 4 | Internet Communication Process (client-server, HTTP/HTTPS, DNS lookup, packets) | 15 |
| 5 | Network Security Basics (Firewall, Antivirus, VPN, Encryption, Authentication) | 15 |
| 6 | Practical Activity (Option A: office network diagram) | 15 |
| | **Total** | **100** |

**Key outcomes**
- Explained the CIA Triad and its application to an e-commerce platform.
- Analysed seven common cyber threats with prevention methods.
- Described core networking concepts with diagrams.
- Mapped the full journey of a web request from client to server and back.
- Designed a labelled office network diagram with private IP addressing.

## Week 2: Network Basics & Security

**Objective:** Understand fundamental networking concepts, how devices communicate, basic network protocols, and security practices.

| Task | Topic | Marks |
|---|---|---|
| 1 | Understanding Network Types (LAN, MAN, WAN, PAN) with comparison diagram | 20 |
| 2 | IP Address & MAC Address (IPv4, private/public IP, practical: private IP screenshot) | 20 |
| 3 | Network Devices (Router, Switch, Modem, Access Point, Firewall) with network diagram | 20 |
| 4 | Network Protocols (HTTP, HTTPS, DNS, TCP, UDP) | 15 |
| 5 | How Data Travels Through a Network (flowchart for `www.example.com`) | 15 |
| 6 | Practical Network Security (10 home Wi-Fi practices, 3 explained in detail) | 10 |
| | **Total** | **100** |

**Key outcomes**
- Compared PAN, LAN, MAN, and WAN with a coverage diagram.
- Explained IPv4, private vs public IP, and IP vs MAC addresses; located the device's private IP.
- Described five network devices and showed how they connect.
- Explained HTTP, HTTPS, DNS, TCP, and UDP, including the TCP three-way handshake.
- Traced a web request from user to server and back with a flowchart.
- Listed ten home network security practices and explained three in depth.
